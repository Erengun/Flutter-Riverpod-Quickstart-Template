# Routing

**Routing.** `lib/router/app_router.dart`: `goRouterProvider` builds a `GoRouter`; routes are named by the `SGRoute` enum (`SGRoute.home.route` → `/home`). It starts on `/splash` (the splash passed to `bootstrap`) and uses Core's `sessionRedirect` with `refreshListenable: sessionListenableProvider`: splash while the session loads, then signed out → `/login` (add pages open to signed-out users to `publicPaths`), signed in → `/home` from login and splash (or back to `from` when an expired session sent the user to `/login?from=<location>`; pass `uri: state.uri` and `expired: ref.read(sessionExpiredProvider)`). Never navigate to home after login or to login after logout yourself: changing the session is enough, and the redirect replaces the stack so back can't undo it. The redirect is `sessionRedirect(...) ?? permissionRedirect(...)`: session first, then the permission guard, which sends a route whose area is missing to Core's `NoPermissionPage` at `SGRoute.noPermission` (links and direct `go()` included) and holds a guarded route on the splash while the permissions are unknown. A route opened before the session or the permissions are known waits on `/splash?from=<location>` and continues there once they are (same safe-location rules as the login `from`): pass `uri: state.uri` to both and `holdOnSplash: permissions.value == null` to `sessionRedirect`, which keeps the splash with a pending `from` instead of sending a signed-in user home. Each route declares its area on its `SGRoute` value (`reports(area: AppAreas.reports)`); a value without `area:` is open to any signed-in user (keep home open, the no-permission page leads there). The guard reads the matched route's name (`state.topRoute`), and `refreshListenable` merges `sessionListenableProvider` and `permissionsListenableProvider`. Every `GoRoute` must set `name:` (`SGRoute.<x>.name`): Core's `NavigationBreadcrumbObserver` (in the router's `observers`) records push/pop/replace breadcrumbs by route name only and skips unnamed routes (go_router names its own pages by path when a route has no `name`, so an unnamed route is either missing or recorded by its path). `test/router/app_router_test.dart` enforces it. Transitions come from the `.fade()` / `.slide()` extensions on `GoRoute` in Core (they keep every other field, sub-routes and `redirect` included, key each page by `state.pageKey`, and throw `ArgumentError` on a route without `builder:`) (`FadeGoRouteExtension` / `SlideGoRouteExtension` in `packages/core/lib/src/router/`), both exported by `package:core/core.dart`.
